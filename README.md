# dsh-theme-toggle

在 DSH Web 界面的左侧栏最底部账号行上提供一个浅色/深色外观切换按钮。

## 行为

- 按钮叠在账号行的右端，只占 28px，账号行的其余区域仍然打开账号菜单。
- 图标对应当前实际配色：浅色显示太阳，深色显示月亮；点击按钮切换到另一种外观。
- 当前为“跟随系统”时，图标按系统实际配色显示，点击后固定为另一种显式外观。
- 侧边栏收成 56px 轨道时，按钮移到账号行下方，避免遮挡 36px 的账号图标。
- 按钮只通过客户端 `theme` 服务读写外观；它只在账号行上挂一个按钮节点，不改动宿主组件结构。

## 外观对齐

尺寸、圆角、悬停底色与焦点环沿用侧边栏自身的图标按钮：

- 展开态：28px，`--dsw-radius-sm`
- 轨道态：36px，`--dsw-radius-md`
- 悬停：`--dsw-alias-interactive-bg-hover`

账号行右侧若出现连接或更新状态，按钮会让位到它们左侧。

## 安装

```
plugin_manager(action="install_bundle", target="<本目录绝对路径>")
```

## 禁用与移除

设置 → 插件 → 找到“外观切换”并关闭，可立即恢复原生界面。

```
plugin_manager(action="remove_bundle", target="dsh-theme-toggle")
```
